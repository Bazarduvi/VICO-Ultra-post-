📖 Manual de uso — WP Ultrapost DUVI
🎯 ¿Qué es esta app?

WP Ultrapost DUVI es un agente IA que genera código WordPress completo y listo para usar: plugins, extensiones, mods de tema, widgets, análisis SEO y contenido humanizado.

⚡ Flujo básico
  1. Configura tu API key en ⚙️ Settings (Groq gratis, Gemini gratis).
  2. Selecciona el tipo de herramienta que quieres generar.
  3. Escribe tu prompt describiendo qué necesitas.
  4. Toca Invocar Duvi — el código aparece a la derecha.
  5. Usa ⬇ ZIP para descargar todos los archivos listos para instalar.
🔌 Tipos de herramienta
  • Plugin WordPress — plugin completo con cabecera, shortcodes y lógica.
  • Extensión Navegador — manifest.json + content scripts para Chrome/Firefox.
  • Mod de Tema — funciones para functions.php, child theme, CSS.
  • Widget / Shortcode — widget de barra lateral o shortcode reutilizable.
  • Análisis SEO — auditoría de contenido con recomendaciones técnicas.
  • Humanizador IA — reescribe texto generado por IA para que suene natural.
🛠 Power Tools
  • Generar Títulos — 5 títulos virales SEO para tu contenido actual.
  • Auditoría Keywords — análisis de palabras clave con sugerencias.
  • Revisar Gramática — corrección de estilo y redacción.
  • Cambiar Tono — reescritura con tono más persuasivo y comercial.
⚡ Lab IA — Generador de Artefactos

Abre el Lab IA desde el botón ⚡ Lab en el topbar.

📊 FLUJO DEL LAB IA
1Selecciona tipo (Plugin / Widget / HTML / Juego…)
↓
2Elige Modo IA (genera con IA) o Modo Manual (pega tu código)
↓
3Escribe prompt o pega código → Generar / Aplicar
↓
4Preview · Refrescar · ⛶ Full · Copiar · Biblio · Compartir
  • Modo IA — Describe lo que quieres, la IA genera el código automáticamente usando el proveedor activo (Groq/Gemini).
  • Modo Manual — Pega tu propio código, haz clic en Aplicar y luego usa Preview/Refrescar para verlo.
  • 🔄 Refrescar — Actualiza el preview sin regenerar. Útil al editar el código manualmente.
  • ⛶ Pantalla completa — Abre el preview en modo fullscreen para probar juegos y apps.
  • Juegos — Al generar un juego HTML5, se añaden automáticamente controles táctiles en cruz (D-pad izquierdo + botones derecha + pausa/restart central) con botón de configuración para mover y redimensionar cada botón táctil.
  • Biblio — Guarda el artefacto en la Biblioteca con nombre personalizado. Aparece en el panel lateral y en la sección de su tipo (Widget, etc.).
  • Compartir — Usa la API nativa del sistema para compartir. En dispositivos sin soporte, copia al portapapeles automáticamente.
  • Prompts rápidos — 30+ prompts predefinidos en categorías: Plugins, Shortcodes, Tema, SEO, Productividad (Calculadora, Conversor monedas, Kanban, Pomodoro), Juegos (Tetris, Space Invaders, Snake, Breakout).
💬 Duvi Chat

Botón Duvi Chat en el topbar. Chatea directamente con el agente IA. Soporta voz 🎤. Puedes cambiar entre Groq y Gemini como proveedor.

📁 Subir ZIP existente

Usa el botón ⬆ ZIP para subir un plugin ya creado. Duvi lo analiza y activa el modo actualización para mejorarlo o modificarlo.

🍅 Pomodoro

Temporizador en el topbar (25 min foco / 5 min descanso). Configurable en ⚙️ Settings.

📡 RSS News

Actívalo en Settings → RSS para ver las últimas noticias de WordPress y tech en el panel lateral.

🔗 Link Buttons

Crea accesos directos personalizados en el panel lateral (requiere activación admin).

🔐 Modo Admin

En ⚙️ Settings → Admin, introduce la clave de administrador para desbloquear funciones extra: link buttons, exportar datos, import/export JSON.
